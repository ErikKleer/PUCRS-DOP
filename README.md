# Projeto DevOps - Fase 1: Configuração e Automação Inicial

Este repositório contém a entrega da **Fase 1** do projeto DevOps na Prática.

## Estrutura do Repositório

- `src/`: Código-fonte da aplicação Node.js.
- `tests/`: Testes automatizados da aplicação.
- `.github/workflows/ci.yml`: Pipeline de Integração Contínua (GitHub Actions).
- `iac/`: Scripts de Infraestrutura como Código (Terraform).
